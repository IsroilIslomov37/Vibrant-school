# Vibrant School — платформа учебного центра

Языки | IELTS | Multilevel (B2, C1), Математика · для взрослых и детей · опыт +10 лет

Платформа для учебного центра на 18 преподавателей и 118+ учеников: статусы активности,
прогресс по курсам и домашним заданиям, приём офлайн-оплаты и проверка ДЗ.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run lint     # oxlint
```

## Демо-доступы

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | `admin` (или `reception`) | `admin` |
| Преподаватель | см. кнопку «Выбрать» на экране входа | `teacher` |
| Ученик | см. кнопку «Выбрать» на экране входа | `student` |

Логины преподавателей и учеников формируются как `имя.фамилия` латиницей.

## Роли

**Администратор** — обзор центра, ученики, оплаты и статусы, курсы, группы,
преподаватели, контроль проверки ДЗ, настройки.
Принимает офлайн-оплату («Принять оплату»): статус ученика по курсу сразу
становится «Активен», срок доступа продлевается, платёж попадает в историю.
Может заморозить обучение, снять активность, добавить ученика и записать его
на дополнительный курс.

**Преподаватель** — свои группы и ученики, выдача домашних заданий, проверка
и выставление оценок с комментарием, отметка проведённого урока (двигает
прогресс группы по программе).

**Ученик** — свой статус и статус по каждому курсу, прогресс по программе и по
домашним заданиям, посещаемость, средний балл, сдача работ, история оплат.
При просроченной оплате сдача домашних заданий по этому курсу закрыта.

## Модель статусов

Статус записи на курс вычисляется из даты `paidUntil`:

| Статус | Условие |
|--------|---------|
| Активен | оплачено, осталось больше 5 дней |
| Истекает | оплачено, осталось 5 дней или меньше |
| Не оплачен | срок оплаты прошёл |
| Заморожен | обучение приостановлено администратором |

Общий статус ученика — «Активен», если активен хотя бы один его курс.
Ученик может учиться на нескольких курсах одновременно; статус, прогресс и
оплата считаются по каждому курсу отдельно.

## Курсы

Английский язык (IELTS, Multilevel B2/C1), Математика, Русский язык,
Узбекский (родной) язык, История.

## Интерфейс

Выпадающие списки — собственный компонент `Select` (нативные `option` рисует
операционная система, в тёмной теме они выглядят чужеродно). Выход из аккаунта
доступен в двух местах:
кнопка «Выйти» внизу сайдбара и меню по аватару в шапке; на телефоне там же
лежит переключатель языка. Действия сопровождаются уведомлениями
(react-toastify): приём оплаты, оценка, выдача задания, сдача работы и т. д.

## Языки интерфейса

Русский, o‘zbekcha, English — переключатель в шапке, выбор сохраняется в браузере.
Все подписи лежат в `src/data/i18n.js`.

## Структура

```
src/
  components/   Layout (сайдбар, шапка, меню пользователя, язык), Login,
                PaymentModal, icons.jsx (react-icons), toast.js (react-toastify),
                ui.jsx (Card, Kpi, Badge, Select, Modal…)
  data/
    seed.js         генератор демо-данных (детерминированный)
    store.js        статусы, селекторы, форматирование
    StoreProvider.jsx  состояние + действия (оплата, оценки, ДЗ)
    i18n.js         словари ru / uz / en
    LangProvider.jsx
  pages/        AdminApp, TeacherApp, StudentApp, StudentDetail
```

## Данные

Демо-база генерируется детерминированно и хранится в `localStorage`
(ключ `vibrant.db`). Все изменения — оплаты, оценки, новые ученики и задания —
сохраняются там же. Сбросить базу: **Настройки → Сбросить демо-базу**.

Для боевого запуска этот слой заменяется на API: точки входа — действия в
`StoreProvider.jsx` и селекторы в `store.js`.
